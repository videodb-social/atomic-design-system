The platform

A single backend for the
entire video lifecycle.

Six primitives that compose. Use one, use all of them. The same SDK across files, live streams, cameras, screen capture, and datasets.

01

Ingest

URL, upload, RTSP, ONVIF, RTMP, screen and audio capture, webhook, dataset. One ingestion path, normalized for everything that comes after.

02

Index

Reusable, additive structures over media: scenes, speech, objects, embeddings, brands, talent, custom domain events. Composable at query time.

03

Memory

Scene-level memory across sessions, archives, and live workloads. Re-indexable forever. Scoped per user, agent, workspace, or fleet.

04

Search

Sub-second, semantic + structured search across petabyte archives. Every hit is a playable clip, materialized in milliseconds.

05

Director

Cut, compose, dub, subtitle, reframe, brand — by code, not by drag-and-drop. The agentic skill SDK for media editing.

06

RTStream

HLS, WebSocket, agent-callable URLs. Output fits the consuming system — live cameras, calls, and screens at 1,000+ feed scale.
